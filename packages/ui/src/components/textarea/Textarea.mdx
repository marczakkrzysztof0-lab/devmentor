# Textarea

## 1. Purpose
Lets the developer describe the problem in their own words — including pasted code — so the mentor can decide before accepting.

## 2. When to use
- „Twoje pytanie” on the request form (#17; 20–4000 characters, R05).
- „Co już robiłeś” (the mentor's description) in the page editor (#14).

## 3. When not to use
| Situation | Use instead | Source |
|---|---|---|
| One short value (name, link, price) | `TextInput` | Spec #14, #17 |
| Showing a question that was already sent | Text + `CodeBlock` (product `QuestionText`, stage 3) | R01.2 |
| Chat composer (Ctrl/Cmd+Enter sends) | Not built — E03 has no spec (What is missing) | K4, P5 |

## 4. Anatomy
Box (panel fill, `border-control`, 4 px), vertical resize handle, text. Label, hint and error come from `FormField`.

## 5. Variants
<Canvas of={Stories.Variants} />

One variant. Height is set with `rows` (default 6); the user can make it taller.

**Character counter (S14, decided 2026-10-19):** only when the spec defines a limit — pass it as `maxLength`: the question 4000 (#17), the mentor's description 2000 (#14). The counter („3201 / 4000 znaków”, Geist Mono) appears from 80 % of the limit; screen readers hear it through a polite live region one second after the user stops typing. No limit in the spec → no counter.

## 7. Behaviour and accessibility
- Native `<textarea>`: Enter makes a new line (code can be pasted and typed). Tab leaves the field.
- Inside `FormField`: id, `aria-describedby`, `aria-invalid`, `required` are set automatically.
- Input is kept after any error (spec #14, #17); never clear the field on a failed submit.

## 8. Content
- Placeholder is a prompt-like example („Co robisz, co już sprawdziłeś i gdzie utknąłeś?”), never the name.
- Long text and code wrap and scroll inside the field; nothing is cut. Code keeps its line breaks.
- Limits come from the spec (question 20–4000 characters after trim, #17); the minimum is checked on blur and submit, the maximum is enforced by `maxLength` and shown by the counter (S14).

## 9. Responsiveness
Full width at every width; at 320 px the field keeps 6 rows and grows with resize.

## 12. Do and don't
| Do | Don't |
|---|---|
| Keep the question after a failed payment start. | Clear the field — the developer loses the text they wrote (spec #17). |
| Visible label „Twoje pytanie”. | Placeholder-only field. |
