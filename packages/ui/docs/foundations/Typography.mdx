# Typography

Two families: **Geist** for the interface and **Geist Mono** for code, file paths, amounts and slugs. Source: DK2, R01.2. The app loads them through `next/font`; Storybook from the local files of the `geist` package (P3). Never from a CDN.

## Roles

| Role | Classes | Size / line height | Weight | Use for | Source |
|---|---|---|---|---|---|
| Page heading | `text-heading-page font-strong` | 24 px / 1.3 | 600 | One per screen: the mentor's name, the state on `/r/{token}` | R01.5 |
| Section heading | `text-heading-section font-strong` | 20 px / 1.3 | 600 | "Czeka na decyzję", "Najbliższe terminy" | R01.5 |
| Body | `text-body` | 16 px / 1.5 | 400 | Question, description, field values | P2 |
| Label | `text-body font-strong` | 16 px / 1.5 | 600 | Field labels | Proposal (P7), WCAG 3.3.2 |
| Metadata | `text-meta text-muted` | 14 px / 1.4 | 400 | Times, hints under fields, row details | R02.3, R01.1 |
| Numbers and amounts | `font-mono` | inherits | inherits | "150 zł", "12:30–12:55" | DK2 |
| Code | `font-mono` on `bg-surface-code` | inherits | 400 | Code in the question, `/m/anna-k` | R01.2 |

## Rules

| Rule | Source |
|---|---|
| Running text is at most about 65 characters per line: use `max-w-text` (`--ds-measure-text` = <TokenValue name="--ds-measure-text" />). | Prompt, WCAG 1.4.8 |
| Only two weights: 400 (`font-regular`) and 600 (`font-strong`). | P2 |
| Hierarchy comes from size and weight, never from coloured words or uppercase eyebrows above a heading. | A01, audyt.md |
| Sizes are in rem, so text follows the user's browser font size. | WCAG 1.4.4 |
| One page heading per screen. | R01.5 |
| No exclamation marks or marketing copy; concrete amounts and states, in Polish. | P29 |
