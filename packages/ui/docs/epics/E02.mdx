# E02 · Paid request and the mentor's decision (#9)

A developer pays up front and sends the question within 5 minutes; the mentor reads it and accepts or declines; a decline, no answer before the slot, or the developer's cancellation before acceptance refunds the money automatically (D02, D04, D05, D08).

## Flow

| # | Step | Who | Screen | Spec |
|---|---|---|---|---|
| 1 | Length (with prices) → slot → name → question → „Zapłać 150 zł i wyślij pytanie” | Developer | S6 `/m/[slug]` | #17 |
| 2 | Hosted Stripe Checkout | Developer | Stripe | #24 |
| 3 | „Czekamy na potwierdzenie płatności” → „Opłacone — czeka na mentora”, „Zapisz ten link” | Developer | S7 `/r/[token]` | #17 |
| 4 | E-mail „Nowe opłacone pytanie…”, list „Czeka na decyzję” | Mentor | S8 `/mentor/requests` | #17, #18 |
| 5 | Question, length, slot → „Akceptuję” / „Odrzucam” with confirmation | Mentor | S9 `/mentor/requests/[id]` | #18 |
| 6 | Optional: „Anuluj i odzyskaj 150 zł” until acceptance | Developer | S7 | #19 |
| 7 | No answer before the slot → automatic refund | System | S7, S8, S9 | #18 |
