# Pattern: Detail view

One object on its own page, with the information needed for the decision and the main action visible without scrolling. Used in: request detail `/mentor/requests/[id]` (#18), request page `/r/{token}` (#17), mentor page `/m/{slug}` (#16).

## Rules

| Rule | Source |
|---|---|
| The state (or deadline) comes first, as a heading-level line: „Zdecyduj do jutra 12:30” | R01.5, P18 |
| The facts needed to decide come before any button: question, length, slot (#18 AC) | Spec #18 |
| Main information and the main action fit the first screen at 1440 and 768 px; on 320 px the action follows the question | R01.5, K6 |
| One primary action; the opposite decision is secondary | R01.5, P18 |
| "Does not exist" and "no access" look the same and show no data | Specs #16, #17, #18 |
| A decided object shows its result and no action buttons | Spec #18 |

## States

| State | Story |
|---|---|
| Ready, action above the fold | main info and action above the fold |
| Does not exist or no access | does not exist or no access |
| Decided | decided (no actions) |
