# Icons

Library: **lucide-react** (P1). Icons support words; they never replace them.

| Size | Token | Class | Use for | Source |
|---|---|---|---|---|
| 16 px | `--ds-icon-size-sm` | `size-icon-sm` | Next to 14–16 px text: links, metadata, "+ okno" | P1 |
| 20 px | `--ds-icon-size-md` | `size-icon-md` | Buttons and alerts | P1 |

Icons draw in `currentColor`, so they take the text colour of their context.

## When an icon needs a label

| Situation | Rule | Source |
|---|---|---|
| Icon next to text | The icon gets `aria-hidden="true"`; the text is the accessible name. | P1, WAI-ARIA |
| Icon alone | Only "×" for removing a time window. It gets an `aria-label` naming the object and a target of at least 24 × 24 px. | P1, WCAG 2.5.8, 4.1.2 |
| State | Never an icon or a colour alone; the state is written in words. | R01.6, WCAG 1.4.1 |
| Forbidden | `Sparkles` and other AI symbols, emoji instead of icons, camera and microphone icons. | A01, R02.5, A06 |
