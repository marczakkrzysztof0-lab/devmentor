# TextInput

## 1. Purpose
Lets the user type one short value — a name, a link, a price — and see it exactly as it will be used.

## 2. When to use
- „Imię” on the request form (#17).
- „Imię i nazwisko”, „Link do publicznej pracy”, „Cena za 25 min” / „Cena za 50 min” with the „zł” suffix, „Adres strony” (read-only after publishing) in the mentor editor (#14).

## 3. When not to use
| Situation | Use instead | Source |
|---|---|---|
| More than one line (question, description) | `Textarea` | Spec #14, #17 |
| Choosing from a known list (time zone, hours) | `Select` | Spec #15 |
| Showing a link to copy | `CopyField` | Spec #14 |

## 4. Anatomy
Box (panel fill, `border-control`, 4 px) → input text → optional suffix („zł”, announced as the field's description).

## 5. Variants

| Variant | When | Source |
|---|---|---|
| Plain | Name, link | — |
| `suffix` | A unit that is not typed: „zł” (currency is not editable) | Spec #14 |

## 7. Behaviour and accessibility
- Native `<input>`; inside `FormField` it gets id, `aria-describedby`, `aria-invalid` and `required` automatically.
- The suffix is linked as a description, so a screen reader says „Cena za 25 min, 150, zł”.
- Use the right `type`/`inputMode`/`autoComplete` (`url`, `numeric`, `given-name`) so phones show the right keyboard.

## 8. Content
- Placeholder is an example, not an instruction. Prices: whole złoty, formatted on display with `Intl.NumberFormat('pl-PL')` (spec #16 Q6).
- Long values scroll inside the field; nothing is cut on save.

## 9. Responsiveness
Full width of its container at every width; 16 px text avoids zoom on focus in mobile Safari (S3).

## 12. Do and don't
| Do | Don't |
|---|---|
| Suffix „zł” outside the typed value. | Asking the mentor to type „150 zł” and parsing it. |
| `readOnly` slug with a hint why it is locked. | A disabled field with no explanation. |

## 13. Related
- Confused with: `Textarea`, `CopyField`.
- Used in: Form pattern, Mentor page editor, Request form.
